# 0.8.10 白天、夜间与跟随系统

## 实现

外观偏好使用独立 AppStorage 保存，默认跟随系统。侧栏菜单、简洁设置和专业设置共用偏好，手动切换即时作用于窗口和弹窗；回到跟随系统时清除应用外观覆盖。切换不修改代理配置或连接状态。

## 验证

- Debug / Release 构建通过；应用签名深度校验、组件摘要和源码清单匹配。
- QingzhouChecks：115 个场景、1201 条断言、0 失败。
- 独立界面检查：11 条断言通过、26 张截图。额外验证默认跟随系统、白天/夜间强制覆盖、保存偏好、恢复深/浅色继承，以及外观切换前后代理配置和连接状态一致。
- 原生交互：设置中切到夜间，打开高级设置弹窗，再在弹窗内切到白天；窗口和已打开弹窗均即时更新。侧栏菜单切回跟随系统后，设置选中项同步。
- 自动化用父级窗口外观模拟系统深浅色变化，没有修改电脑的系统外观，也没有调用真实连接、恢复或辅助服务安装。
- 未取得新增 UI 的全量 100% 行/分支覆盖与全项目 80% 变异检出证据，未降低既有质量门槛。旧系统仍仅验证编译兼容。

## 安装与使用

安装包更新到未运行的“轻舟代理（新版）”，保留当前运行的液态玻璃版及现有网络连接。先正常退出当前版本，再打开新版。TUN/完整接管切换新版后需要通过设置中的“安装 / 更新辅助服务”完成管理员授权。

临时构建缓存和被替换的旧应用移入废纸篓，最新应用包、预览及检查日志保存在本次 outputs 交付目录。
