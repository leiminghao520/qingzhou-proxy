# 直连与网络绕过统一管理

本次新增 macOS 客户端“网络绕过”，版本 0.11.0（45），辅助协议版本 5。实现与本地检查已完成；指定出口的真实内核防火墙、银行 Horizon 登录与桌面隧道尚未验收，不能作为银行连接已修复或生产交付验收通过的结论。

## 使用方式

1. 在“分流规则 → 网络绕过”新增目标。普通 DIRECT 仍由核心直接访问，原有规则顺序不变。
2. 普通域名使用“精确域名”；需要包括子域时选择“域名及子域”。批量粘贴中 `*.example.com` 表示域名及子域，普通域名表示精确匹配，逗号和换行均可分隔。
3. 搜索目标或备注、逐项编辑、启停和多选删除均按 UUID 操作。格式错误阻止保存；重复项提示并跳过；覆盖项提示但保留，不能自动扩大网段。
4. 修改先进入草稿，预览显示新增、修改、删除和覆盖关系。断开时只保存；连接时一次应用只执行一次重配置，验证成功后提交保存。失败尝试恢复原运行配置，错误保留在预览及应用状态中。
5. 普通 DIRECT 的精确域名、域名后缀、IP/CIDR 可选择“转为绕过”。预览明确提示优先级提升；只删除本次转换的普通规则，其他规则按原顺序保留。关键词、GEOIP、ASN 等不提供等价转换。
6. 设置页仅显示摘要和“管理网络绕过”入口。路径诊断读取系统实际代理选择、解析结果、目标路由及指定出口状态；规则解释仍是静态推演。

系统代理例外依赖应用遵循系统代理配置。显式指定代理的应用可能忽略例外。普通路由方式仍由系统选择真实出口，不承诺指定银行网卡。

## 模型与运行路径

`AppState.networkBypasses` 保存 UUID、类型、目标、备注、启用、出口、网络服务 ID 和网关。主机地址内部规范化为 `/32`、`/128`，主机系统代理例外生成裸 IP。文件读取也校验并规范化新增字段。旧保护域名和额外网段按内容生成稳定 UUID，无损迁移并保留旧企业保护语义；旧字段保留兼容镜像。普通 DIRECT 不自动迁移。配置备份包含新增字段。

统一配置生成系统代理例外、TUN 排除、核心优先保护及原系统 DNS 策略。精确域名不会扩大为子域。三种接管模式共享该配置。

指定出口首版只接受 IP/CIDR，保存网络服务 ID，运行时解析接口。辅助服务验证网关并使用现有路由所有权日志；相同外部路由只核验，不认领；同前缀竞争出口拒绝应用。旧辅助服务在发送启动命令前被拒绝，不静默忽略指定出口。

拒绝保护使用独立 PF 锚点，要求实际根过滤规则只有可验证的 Apple 通配锚点且没有竞争子锚点。保护规则限制目标只能从指定接口发出，清理该目标的旧连接状态；无法确认保护优先级时明确失败，不能覆盖企业 VPN 的根规则。恢复只清理仍与记录一致的自有锚点和启用凭据，遇外部改写或写入结果不明保留恢复记录。

指定网卡掉线时不进入撤销防火墙的通用重建流程，保留拒绝路径；恢复后重新验证并维护路由。若主网络变化需要整体重建，首版保留保护并提示手动重新连接，尚未实现带保护连续性的自动整体重建。

## 未完成的验收与已知限制

- 严格覆盖率门禁未满足。Swift 检查程序整体行覆盖率 80.93%；新绕过模型、诊断与网络服务读取的分项见 `coverage.log`。UI 和真实管理员操作不在该覆盖范围内；分支覆盖未取得可用报告。Swift 项目没有 JVM/PIT 运行目标，6 项定向变异不能替代完整变异门禁。
- 原生 List 隔离渲染日志出现 macOS `NSTableView` 重入警告，检查未崩溃且搜索、转换和滚动通过；仍需在正常应用窗口进行长期交互回归。
- 批量错误和覆盖预览已进行模型检查；逐项编辑、批量粘贴及多选删除尚未全部完成原生鼠标键盘端到端验收。
- PF 真实语法加载、内核拒绝路径、路由拔线恢复、崩溃重启及三种真实接管模式尚未在独立测试机验收。当前机器存在企业 VPN 防火墙配置，不能将文件采样当作内核兼容性证明；不满足锚点前提时功能会拒绝应用。
- 指定出口只对正常可管理的接口及路由负责；企业 VPN 外部改写防火墙、内核策略或接口时只能报告保护无法确认，不能承诺覆盖企业 VPN 行为。
- 银行实网验收尚未执行。需要网口有效时核对目标实际经过用户指定网关，完成 Horizon 登录及桌面安全隧道，再拔线确认不会改走 Wi-Fi 或代理。普通 HTTPS 成功不能替代该项。
