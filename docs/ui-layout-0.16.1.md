# 汐航 0.16.1（83）布局修复

原因：当前线路卡内部宽度约 170 点，协议与延迟同排时会压缩“历史 · 775 ms”等文本；概览原生纵向滚动指示条会覆盖右侧内容。

改动：协议与延迟分行；延迟胶囊按固有宽度排版，保留完整辅助功能标签和完整测试时间的悬浮提示。隐藏内容页的滚动指示条，同时保留原生滚动容器，首页与线路列表显式关闭指示条。网络、测速和状态判定逻辑没有修改。

验证：`bash scripts/interface-checks.sh /绝对路径/截图目录 --layout-only`。本轮通过 10 项检查，生成 9 张截图，覆盖历史 775、9999、99999 ms，当前 99999 ms、超时、深浅色、820×620 简洁窗口，并核对纵向滚动条隐藏及实际滚动到底部。
