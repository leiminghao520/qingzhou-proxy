# 0.12.1 链路本地绕过修复

截图中的 bypassSnapshot / fe80::/10 / EINVAL(22) 是 0.12.0 原生接口回归：地址编码器在 RTM_GET 无作用域查询到达内核前错误拒绝它。现在只读 GET 允许零作用域，由内核选择；写入和网关仍要求明确接口。

同时修正绕过规划：链路本地目标保留所有已确认网卡的作用域路径，去掉被基路由覆盖的缓存项，不把一次查询选中的接口扩成全局 fe80::/10。捕获只排除实际确认的前缀，并在规划和激活前核对原路径。系统维护的作用域路径生命周期变化不被当作轻舟自有路由遭覆盖；全局及轻舟写入路由仍严格核验。

验证通过：新增与既有原生夹具 2,134 断言；QingzhouChecks 144 场景、19,782 断言；监控 98 断言；保护 82 断言；14 个定向变异全部检出。当前网络只读对照包含无作用域及指定网卡的 fe80:: 查询；真实绕过快照保留 9 条作用域路径，0 条新增全局路径。没有执行内核写入或实网重连，因此不声明真实 TUN 连接验收通过或达到启动耗时目标。
