# 轻舟代理 0.8.11 Windows 界面预览版

普通用户下载 `qingzhou-0.8.11-windows-x64-setup.exe`，双击安装后从桌面“轻舟代理”打开，无需 Flutter、Go、Python 或 Visual Studio。更新前先从旧版托盘断开并退出，避免旧进程占用安装文件。安装网络服务时需要 UAC 授权；安装不会自动启用代理。

## 界面变化

- 固定顶栏显示“简洁 / 专业”切换，桌面与窄屏均可找到；滚动设置页也保留入口。
- 简洁模式提供连接、线路、订阅、设置；专业模式提供额外的策略、规则、监控、配置入口。原有设置页开关继续可用。
- 模式保存到本地偏好。切换时保留仍然可用的页面，从专业专属页面切回简洁时回到连接页；切换不触发代理连接。
- 重做桌面侧栏、配色、明暗主题、连接状态区、当前线路和操作按钮，减少默认表单的空白与整行长按钮。
- 窗口、任务栏和托盘图标沿用 macOS 的轻舟纸船图标，移除 Flutter 默认标识。
- 首页展示实际选中的节点或策略组名称；线路数量只表示已添加配置，不表示测速或实网检查通过。
