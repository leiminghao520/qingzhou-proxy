# 轻舟 0.12.6（53）页面与草稿优化离线报告

本轮完成概览截断、连接列表分页提示、搜索空态、节点重复排序和草稿离页保护。候选已构建、以 ad hoc 签名并通过 deep/strict 签名核验。**未安装到 Applications，未更新或启用辅助服务，未重连或修改宿主路由、DNS、系统代理。** 保留原有未提交工作，没有提交或推送。

## 实现结果

- 概览状态、完整接管标签和控制按钮自适应分行；节点名有完整悬停文本，保护及验证详情可展开。已检查明暗主题、长中文、长节点名及窄布局。
- 连接先对完整数据筛选和排序，首次显示 1,000 条，每次再加载 1,000 条；显示已展示、匹配和全部数量。筛选或排序变化重置额度，关闭全部仍发送完整连接关闭请求。
- 连接、节点、简洁线路和网络绕过区分无数据与无匹配，提供对应清除入口。
- 节点和连接展示模型缓存计算结果；保留原排序语义，数据、筛选、配置、网络失效及延迟过期正确刷新。延迟过期主动通知页面，徽标与排序使用一致的新时钟。干净绕过列表不重复发布相同数据。
- SessionDraftStore 仅驻留内存，按配置及编辑类别隔离网络设置、端口、快捷键、规则、原始文本及网络绕过。普通切页、模式切换及关闭主窗口保留草稿；切配置、关闭修改过的编辑弹窗和退出时确认。退出取消先于网络释放，外部修订冲突拒绝覆盖，失败保留输入，成功只清理对应草稿。保存期间相关输入与既有操作锁同步。
- TUN、路由、捕获范围、DNS 与辅助服务实现未做本轮功能修改；版本号与构建号按候选统一更新。CoreConnection 和 ConnectionMetadata 仅新增 Equatable 一致性供展示缓存比较。
