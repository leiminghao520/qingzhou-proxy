## 升级注意事项

辅助服务会校验客户端代码身份。即使版本号相同，重新构建客户端后也需要在新应用的设置中点击“安装 / 更新辅助服务”，由用户完成 macOS 管理员授权；否则旧服务可能拒绝新客户端，界面显示“辅助服务控制通道已中断”。不要通过关闭签名或身份校验规避授权。
