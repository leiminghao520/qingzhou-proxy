# 0.8.9 液态玻璃界面验证

## 变更

- macOS 26 使用原生 Liquid Glass，作用于侧栏选中态、模式切换和连接操作；正文使用磨砂卡片，保留文字可读性。
- 配套浅色/深色渐变背景、细边缘高光和弹簧过渡。专业模式的入口及连接操作同步适配。
- macOS 14/15 保留材质兼容分支；减少透明度或提高对比度时回退实色，减少动态效果时不添加弹簧动画。
- 仅修改界面及版本标识，没有修改代理、路由、DNS、凭据或辅助服务安全校验逻辑。

## 验证

- Debug 与 Release 构建通过；应用签名深度校验、组件 SHA-256 和源码清单匹配。
- QingzhouChecks：115 个场景、1201 条断言、0 失败。
- 独立界面检查：4 条断言通过，生成 22 张窗口截图，覆盖浅色、深色、窄窗口、连接异常及辅助功能回退。
- 原生交互确认：侧栏进入线路、玻璃模式切换进入专业概览、切回简洁连接页，保留选中线路与未连接状态。检查只操作模拟模型，没有启动真实代理。
- 玻璃选中层已与文字合并合成，修正初版材质折射前景文字造成的模糊。
- macOS 14/15 只验证编译兼容分支，未在旧系统实机验证。减少动态效果检查不代表逐帧动画性能基准。
- 新增界面的 100% 行/分支覆盖率及全项目 80% 变异门禁仍未取得完整证据；没有降低项目门槛。其他既有门禁差距见 0.8.8 验证记录。

## 运行与升级

新版以“轻舟代理（液态玻璃）”并列安装，未停止正在运行的版本或改变其网络设置。需要先正常退出旧版，再打开新版。TUN/完整接管需要在新版设置中更新辅助服务，并由用户完成 macOS 管理员授权；重新构建后的客户端签名变化不能复用旧客户端授权。

## 复现

```sh
scripts/swift-local.sh build --product Qingzhou
scripts/swift-local.sh run QingzhouChecks
bash scripts/interface-checks.sh
scripts/build-app.sh outputs
```

界面检查中的辅助功能存储键注入仅存在于独立检查程序，不会进入正式应用，也不修改系统辅助功能偏好。
