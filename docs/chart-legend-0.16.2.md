# 汐航 0.16.2（84）图例裁剪修复

根因：RateChart 的嵌入模式 padding 为 0，但仍对整个 VStack 应用 16 点圆角 clipShape，导致靠近右上角的“下载”字形被遮盖。

改动：圆角仅用于图表卡片的背景和边框，不裁剪图例及内容；图例按自身宽度排列。保留嵌入流量卡与独立图表的外观、坐标轴和选择读数。

验证入口：`bash scripts/chart-legend-checks.sh /绝对路径/输出目录`。检查程序直接提取当前源码的图表、主题和格式化函数，渲染嵌入宽布局、嵌入窄布局、独立布局各自的深浅色版本，不读取用户配置、钥匙串或网络。本轮修复前后各生成 6 张原生渲染图，已目视核对裁剪消失，独立布局外观正常。
